# LumaStudio Vector

レーザーカッター専用の日本語ベジェ曲線Webアプリです。

- [アプリを開く](https://lumastudiovector.altimix.jp/app)
- [公式サイト・使い方](https://lumastudiovector.altimix.jp/)
- [v0.3.0の配布ファイル](https://github.com/altimix/lumastudio-vector-releases/releases/tag/v0.3.0)

## できること

Illustratorの基本ペン・アンカー操作に合わせた曲線編集、mmの寸法、切断と線彫刻のレイヤー、保存・復元、SVG・DXF出力に対応します。SVGは曲線を保持し、DXFは許容誤差0.05 mmの折れ線で保存します。

PCブラウザーのマウス・キーボード操作を推奨します。実機への接続・送信や速度・出力設定はレーザー制御ソフトで行ってください。LightBurn等での実取り込み・実機加工は未検証です。

## 基本テンプレート

上部の「テンプレート」または「新規」から、コースター、キーホルダー、スマホスタンド、本立て、ペン立て、小物トレー、カエデ、アクリルスタンドを選べます。寸法・板厚・差し込み穴の調整をプレビューし、「このテンプレートで作成」で編集を始めます。キャンセルは現在の作品を保持し、作成後はUndoで戻せます。

組立品は差し込み＋接着の設計です。板厚は実測値を入力し、切り幅・嵌合は端材で試してください。加工配置が機械の加工範囲に収まるか確認し、必要に応じて部品を並べ替えてください。部品名の文字は加工線に含めません。実機での加工、接合強度・転倒安定性は未検証です。

## カエデの見本

「新規」→「カエデ・オーナメント」→「このテンプレートで作成」から、七つの葉先と葉脈を持つ見本を開けます。150 × 141 mmの外周と直径5 mmの吊り穴は切断、31本の葉脈は線彫刻です。ベジェ曲線として形や大きさを編集できます。アプリの更新だけでは既存の自動保存データを置き換えません。

## ペンで輪郭を閉じる

始点に近づくと接続の目印が出ます。クリックで輪郭を閉じ、そのままドラッグするとハンドルを引き出せます。接続範囲は直径24pxで、ズームしても画面上の押しやすさを保ちます。

## アクリルスタンド

上部の「アクリルスタンド」から透過PNG/WebPを選ぶと、余白・差し込み足・穴付き台座を作れます。「サンプルのねこで試す」で体験できます。切断と線彫刻は別々のSVG/DXF、カラー印刷は実寸PDFで出力します。裏面印刷用の反転と白版の参考マスクも用意できます。

白版の参考マスクは特色指定ではなく、RIPで白インクを設定する際の範囲確認用です。参照画像は固定位置なので、加工線を動かしたら位置を確認してください。背景削除と面・写真の彫刻には未対応です。印刷位置・切り幅・はめあいは実機で試作して確認してください。

## 公開配布について

このリポジトリは公開配布専用です。開発用のソース、テスト、Git履歴、source mapは含みません。site/はCIで確認したビルド済みWebアプリと公式サイトです。ブラウザーへ配信するJavaScript自体は閲覧可能です。

ZIPは静的Webホスティング用です。Webルートに展開すると公式サイトが /、編集アプリが /app/ に配置されます。index.htmlを直接ダブルクリックする使い方には対応していません。通常は上記の公開アプリURLをお使いください。

## データと条件

編集データはブラウザー内で扱います。ブラウザーのデータ削除で自動保存は消えるため、.lumavector制作ファイルも保存してください。
