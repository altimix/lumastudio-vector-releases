# LumaStudio Vector

レーザーカッター専用の日本語ベジェ曲線Webアプリです。

- [アプリを開く](https://lumastudiovector.altimix.jp/app)
- [公式サイト・使い方](https://lumastudiovector.altimix.jp/)
- [v0.4.0の配布ファイル](https://github.com/altimix/lumastudio-vector-releases/releases/tag/v0.4.0)

## できること

Illustratorの基本ペン・アンカー操作に合わせた曲線編集、mmの寸法、切断と線彫刻のレイヤー、保存・復元、SVG・DXF出力に対応します。SVGは曲線を保持し、DXFは許容誤差0.05 mmの折れ線で保存します。

PCブラウザーのマウス・キーボード操作を推奨します。実機への接続・送信や速度・出力設定はレーザー制御ソフトで行ってください。LightBurn等での実取り込み・実機加工は未検証です。

## 原寸画像と自動縁取り

「画像・縁取り」または画像のドロップでPNG/JPEG/WebPを読み込み、幅・高さをmmで指定できます。縦横比は固定で、元の透明・白い余白を含めた寸法です。画像のDPIを取得できる場合は元画素数から実寸に換算し、不明な場合は初期幅100 mmを仮の寸法として表示します。

自動縁取りは透明・白背景の外周を抽出し、0〜20 mmの余白を付けます。内部の穴はくり抜かず、離れた部分も保持します。画像は1枚。作り直した自動輪郭は置換し、重複追加しません。画像の編集で位置・寸法を変えると連動する輪郭も追従します。作成後はアンカーで調整できます。画面の濃さは印刷に影響しません。

白背景の指定は輪郭抽出だけに作用し、印刷用画像の背景や白版を削除しません。複雑な写真の人物切り抜きは未対応です。画像の解像度によって輪郭精度は変わるため、プレビューと試作で確認してください。

## 機種に合わせた加工エリア

キャンバス上部の寸法から、標準加工範囲を選べます。画像や図形の実寸は変更しません。

| 機種 | 幅 × 奥行 |
| --- | --- |
| xTool P3 | 915 × 458 mm |
| Epilog Helix 24 | 610 × 457 mm |
| FABOOL Laser CO2 | 600 × 440 mm |

メーカー仕様へのリンクを選択画面に用意しています。機種の自動判定は行いません。手動ではアプリ上限3,000 × 3,000 mmまで指定できますが、実際に加工できる範囲は機械・固定具・拡張部品に合わせて確認してください。

## UV印刷用アクリルキーホルダー

「テンプレート」→「アクリルキーホルダー」→「画像から作成」を選びます。透過PNG/WebPから本体と上部中央の吊り穴を作成し、絵の高さ・余白・穴径・穴のまわりの幅を調整できます。穴は短いつなぎで本体に寄せ、絵に重なる場合だけ少し上げます。スタンドと同じねこの見本でも試せます。

「加工データを書き出す」から、カラー印刷PDF・白版の参考マスク・切断線をZIPで保存できます。裏面用の反転も選べます。作成後の印刷画像と加工線の編集は独立しています。金具との適合・縁の強度・実機での印刷位置合わせは試作で確認してください。

## 基本テンプレート

上部の「テンプレート」または「新規」から、コースター、キーホルダー、スマホスタンド、本立て、ペン立て、小物トレー、カエデ、アクリルスタンド、アクリルキーホルダーを選べます。寸法・板厚・差し込み穴の調整をプレビューし、「このテンプレートで作成」で編集を始めます。キャンセルは現在の作品を保持し、作成後はUndoで戻せます。

組立品は差し込み＋接着の設計です。板厚は実測値を入力し、切り幅・嵌合は端材で試してください。加工配置が機械の加工範囲に収まるか確認し、必要に応じて部品を並べ替えてください。部品名の文字は加工線に含めません。実機での加工、接合強度・転倒安定性は未検証です。

## カエデの見本

「新規」→「カエデ・オーナメント」→「このテンプレートで作成」から、七つの葉先と葉脈を持つ見本を開けます。150 × 141 mmの外周と直径5 mmの吊り穴は切断、31本の葉脈は線彫刻です。ベジェ曲線として形や大きさを編集できます。アプリの更新だけでは既存の自動保存データを置き換えません。

## ペンで輪郭を閉じる

始点に近づくと接続の目印が出ます。クリックで輪郭を閉じ、そのままドラッグするとハンドルを引き出せます。接続範囲は直径24pxで、ズームしても画面上の押しやすさを保ちます。

## アクリルスタンド

上部の「アクリルスタンド」から透過PNG/WebPを選ぶと、余白・差し込み足・穴付き台座を作れます。「サンプルのねこで試す」で体験できます。切断と線彫刻は別々のSVG/DXF、カラー印刷は実寸PDFで出力します。裏面印刷用の反転と白版の参考マスクも用意できます。

白版の参考マスクは特色指定ではなく、RIPで白インクを設定する際の範囲確認用です。作成直後の画像と加工線は同じmm座標です。作成後の編集は独立しているため、移動や拡縮を行ったら位置を確認してください。背景削除と面・写真の彫刻には未対応です。印刷位置・切り幅・はめあいは実機で試作して確認してください。

## 公開配布について

このリポジトリは公開配布専用です。開発用のソース、テスト、Git履歴、source mapは含みません。site/はCIで確認したビルド済みWebアプリと公式サイトです。ブラウザーへ配信するJavaScript自体は閲覧可能です。

ZIPは静的Webホスティング用です。Webルートに展開すると公式サイトが /、編集アプリが /app/ に配置されます。index.htmlを直接ダブルクリックする使い方には対応していません。通常は上記の公開アプリURLをお使いください。

## データと条件

編集データはブラウザー内で扱います。ブラウザーのデータ削除で自動保存は消えるため、.lumavector制作ファイルも保存してください。
